节点捕食者 Pro v2.1 - 使用说明
================================

一、运行
直接双击 app.exe（无黑色控制台）。源码运行：python app.py。
无界面运行：python runner.py --config config.json。

二、三个主要按钮
1. 筛选策略
   - 延迟门槛：360ms / 500ms / 800ms / 自定义。
   - 严格（推荐）= 3 轮 TCP 全部成功 + TLS 握手校验 + 抖动限制。
   - 均衡 = 3 轮中至少 2 次成功；极速 = 1 轮。
   - 最大抖动默认 120ms；最多保留数量建议 100-300。
   - 并发线程默认 80，可调到 120-150。

2. 地区选择
   默认 52 个常用国家/地区全部勾选。点击某个地区即可取消。
   未识别地区的节点默认剔除，可勾选保留无法识别地区。

3. 开始抓取
   显示实时进度百分比、当前阶段、已测/总数和日志。
   运行中可点停止任务，不会覆盖旧输出文件。

三、支持协议
VLESS（含 Reality、XTLS Vision、VLESS Encryption、XHTTP、HTTPUpgrade、WS、gRPC、H2）、
VMess、Trojan、Shadowsocks、Hysteria、Hysteria2、TUIC、WireGuard、SSH、AnyTLS、
HTTP、SOCKS5。
不能规范化成 Hiddify / sing-box / Clash Meta 结构的节点会自动剔除。

四、每次输出 4 份文件
- clean_nodes.txt：Base64 编码的 V2Ray 分享链接订阅。
- clean_nodes_plain.txt：纯分享链接。
- clean_nodes.yaml：Clash / Clash Meta / Mihomo 配置。
- clean_nodes_singbox.json：sing-box 配置，支持全协议。

五、Hiddify 建议
- 全协议订阅优先导入 clean_nodes_singbox.json。
- 只使用分享链接时导入 clean_nodes.txt。
- Clash / Clash Meta 用户使用 clean_nodes.yaml。

六、质量策略
- TCP 协议：多轮 TCP 建连 + TLS 握手/证书校验 + 抖动过滤 + 综合评分排序。
- UDP/QUIC 协议：Hysteria / Hysteria2 / TUIC / WireGuard 不做 TCP 假测速，
  只做地址、端口、字段和 DNS 静态校验，并排在 TCP 质检节点之后。
- 免费节点波动大，建议严格模式、抖动 120-180ms。
- 本工具不验证机场账号是否到期，只验证节点结构和基础连通性。

七、GitHub 每 12 小时自动更新
最简单的方法：双击本目录下的 publish-now.cmd。
浏览器会打开 Classic Token 创建页面，勾选 repo 和 workflow 权限，创建并复制 Token（不要用 Fine-grained token），
粘贴到窗口后直接回车使用默认仓库名。脚本会自动创建仓库、上传项目、
触发第一次抓取，并打印手机订阅地址。

自动更新结果会发布到 output 分支，手机 Hiddify 添加：
https://raw.githubusercontent.com/你的用户名/你的仓库名/output/clean_nodes_singbox.json
更多步骤见 README.md。
